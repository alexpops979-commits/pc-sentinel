# Формат: ключ = значение, поля через |.
# Строки, начинающиеся с # или ;, игнорируются.

# --- Связки API ---------------------------------------------------------
# api = <функции через +> | <название> | <critical|warning|info> | <объяснение>
#
# critical — связка сама по себе означает вредоносное поведение;
# warning  — требует подтверждения другими признаками;
# info     — встречается и у нормальных программ (установщики, бэкапы),
#            поэтому только добавляет вес к общей картине.
#
# По отдельности каждая из этих функций есть в половине нормальных программ,
# поэтому смотрим именно на сочетание.

api = VirtualAllocEx + WriteProcessMemory + CreateRemoteThread | Внедрение кода в чужой процесс | critical | Файл умеет выделять память в другом процессе, писать туда код и запускать его — это классическая инъекция
api = URLDownloadToFile + WinExec | Загрузка и запуск из сети | critical | Файл скачивает исполняемый файл и сразу запускает его
api = SetWindowsHookEx + GetAsyncKeyState | Перехват клавиатуры | critical | Сочетание хуков и опроса клавиш характерно для кейлоггеров
api = CryptEncrypt + FindFirstFile + FindNextFile | Шифрование файлов | critical | Файл перебирает файлы на диске и шифрует их — признак шифровальщика
api = CreateService + StartService | Установка службы | info | Файл создаёт и запускает службу — так закрепляются в системе
api = AdjustTokenPrivileges + OpenProcessToken | Повышение привилегий | info | Файл меняет собственные привилегии процесса
api = IsDebuggerPresent + VirtualProtect | Обход отладки | info | Файл проверяет отладчик и меняет защиту памяти — типично для упакованных образцов
api = NtCreateThreadEx + NtWriteVirtualMemory | Инъекция через ntdll | critical | Файл работает с процессами напрямую через ядро, минуя обычные API
