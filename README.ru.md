# PC Sentinel

Интеллектуальная система диагностики и оптимизации ПК. Объясняет, **почему** компьютер тормозит,
что именно съедает FPS и какие процессы ведут себя подозрительно — вместо простого списка цифр.

Приложение состоит из двух частей:

| Часть | Технологии | Назначение |
|---|---|---|
| **Агент** (`agent/`) | Rust, только стандартная библиотека + Win32 FFI | Собирает реальную телеметрию, проверяет подписи, анализирует автозапуск и сеть, отдаёт JSON по HTTP на `127.0.0.1` |
| **Интерфейс** (`src/`) | TypeScript + собственный SVG-графический слой, дизайн-система на CSS | Шесть экранов дашборда в едином тёмном неоновом стиле |

Окно приложения открывается как WebView2-приложение (Edge в режиме `--app`), без адресной строки и вкладок.
Внешний вид и данные — полностью локальные: агент слушает только `localhost`, ничего не отправляет в сеть.

## Возможности

### 01. FPS и производительность
- График frametime с выделением выбросов и скользящим средним.
- Статистика: средний FPS, максимум, P95, P5, 1% low, 0.1% low, оценка плавности.
- Пороговая диаграмма «доля времени выше N FPS» и гистограмма frametime.
- Подсчёт микрофризов и текстовый вывод: что именно портит плавность.
- Импорт захватов PresentMon / CapFrameX (CSV) — разбор выполняется в интерфейсе, файл никуда не уходит.
- Пока захватов нет, экран показывает пустое состояние: демонстрационных данных в приложении нет.

### 02. Process Intelligence
- Живой список процессов: CPU, память, потоки, путь, PID.
- Сортировка по любой метрике, фильтр через поиск в шапке (Ctrl+K).
- Аномалии: процессы из пользовательских папок с высокой загрузкой.
- Автозагрузка: `HKLM/HKCU → Run`, `RunOnce`, папки Startup — с отметкой подозрительных записей.
- Сетевые соединения процессов: локальный/удалённый адрес, состояние, владелец-PID.
- Завершение процесса с подтверждением; системные процессы защищены.

### 03. Защита: майнеры и трояны
- Проверка цифровых подписей через `WinVerifyTrust`, включая **каталожные** подписи системных файлов.
- Эвристика скрытого майнинга: шаблоны имён, `stratum+tcp`, `--donate-level`, `randomx`, `cryptonight`.
- Неподписанные процессы из `%TEMP%`, `Downloads`, `AppData`, `Public`.
- Скриптовые способы автозапуска (`wscript`, `mshta`, `.vbs`, скрытый PowerShell) — типичная маскировка.
- SHA-256 исполняемых файлов подозрительных процессов.
- Подозрительные сетевые соединения найденных процессов.

### 04. Проверка на вирусы
- Свой движок без внешних антивирусов. **Быстрая** проверка смотрит файлы запущенных
  процессов, `System32`/`SysWOW64`, `Program Files`, `ProgramData`, пользовательские
  папки, временные файлы и автозапуск — те же области, что у Kaspersky. **Полная**
  открывает каждый файл на всех локальных дисках. Прогресс — в процентах и по числу
  объектов: сначала считается, сколько предстоит проверить.
- **Тип файла по сигнатуре**: программа с расширением `.txt` распознаётся как
  программа, а не как текст.
- **Внутрь архивов**: ZIP распаковывается собственным inflate, каждая запись проверяется
  теми же правилами. Есть защита от zip-бомб (предел распаковки и степени сжатия).
- **Документы Office**: макрос VBA, который вызывает оболочку, — типичный способ
  запустить код из вложения.
- **Вложенный PE**: исполняемый файл, спрятанный внутри другого файла, ищется по
  структуре заголовка, а не по случайным байтам `MZ`.
- **Кеш проверенного** (как iSwift у Kaspersky): неизменённый файл, признанный чистым,
  при следующей проверке не читается. Ключ — путь, размер и время изменения.
- **Разбор PE**: секции, энтропия, таблица импорта, упаковщики, данные после секций,
  TLS-callbacks, точка входа. Признаки складываются в общую оценку — поодиночке они
  встречаются и у нормальных программ.
- **Правила в стиле YARA** (`yara.txt`): текстовые и hex-шаблоны с `??`, условия `any`/`all`.
- **Связки API** (`heuristics.txt`): инъекция кода, кейлоггер, шифрование файлов, дроппер.
- База SHA-256 (`signatures.txt`) и тестовый файл EICAR для самопроверки.
- Файл с действительной подписью издателя не попадает в находки из-за структуры:
  `kernel32.dll` тоже умеет писать в чужой процесс, но это не вирус.
- Обход не раскрывает junction и символьные ссылки (в профиле Windows есть
  самоссылающийся `AppData\Local\Application Data`), а файлы крупнее 32 МБ
  читает только началом — иначе полная проверка читает десятки гигабайт.
- **Папки других антивирусов не сканируются.** Их защита снимает посторонний
  процесс, который читает их файлы, — так же поступает любой антивирус.
  Команда `--trust` показывает, что добавить в исключения Kaspersky, и вносит
  папки приложения в собственный список исключений.
- У каждой находки — меню «Устранить»: исключить, игнорировать, открыть папку, узнать больше.

### 05. System Health Score
- Общая оценка 0–100 и разбивка по компонентам: CPU, память, накопители, защита, охлаждение.
- История оценки (точка раз в минуту, хранится сутки) и графики нагрузки.
- Персональные рекомендации с объяснением причины и последствий.
- Сравнение «было → стало» по ключевым метрикам.

### Оптимизация
- Рекомендации с оценкой эффекта и риска: автозапуск, питание, временные файлы, DNS, хранилище.
- Безопасные действия: перед отключением автозапуска команда сохраняется в резервную копию.
- Очистка временных файлов — только то, что старше 7 дней.

## Установка как приложения

```bat
build.bat     :: интерфейс + агент + иконка и версия в exe
install.bat   :: копирование в LocalAppData и ярлыки
```

`install.bat` делает приложение обычным:

- копирует сборку в `%LOCALAPPDATA%\PCSentinel\app`;
- создаёт ярлык **«PC Sentinel»** на рабочем столе и в меню **Пуск** — с вашей иконкой;
- exe получает встроенную иконку (16–256 px), описание «PC Sentinel — диагностика и оптимизация ПК»,
  версию 1.0.0.0 и манифест (Per-Monitor V2 DPI, UTF-8, поддержка Windows 10/11).

Запуск — с ярлыка. Закрыли окно — процесс завершается сам, в фоне ничего не висит.

Удаление:

```bat
"%LOCALAPPDATA%\PCSentinel\app\pc-sentinel.exe" --uninstall
```

Удаляются ярлыки и каталог приложения; история и настройки в `%LOCALAPPDATA%\PCSentinel` остаются.

## Запуск без установки

Требуется Windows 10/11 (WebView2/Edge уже установлены в системе).

```bat
run.bat
```

Скрипт собирает интерфейс и агент (если нужно) и запускает приложение в отдельном окне.

Полезные флаги агента:

```bat
pc-sentinel.exe --no-window          :: только API, без окна
pc-sentinel.exe --port 47900         :: другой порт
pc-sentinel.exe --diag               :: диагностика подсистем в консоль
pc-sentinel.exe --scan "C:\Папка"    :: проверка папки или файла, находки в консоль
pc-sentinel.exe --scan "C:\Папка" --out report.txt   :: то же, отчёт в файл
pc-sentinel.exe --pe "C:\Файл.exe"   :: что движок увидел в PE: секции, импорт, признаки
pc-sentinel.exe --rules              :: какие правила и эвристики загружены и откуда
pc-sentinel.exe --trust              :: доверенные пути: что добавить в исключения Kaspersky
pc-sentinel.exe --install            :: установка (то же, что install.bat)
pc-sentinel.exe --uninstall          :: удаление ярлыков и каталога приложения
```

> **Если агент не запускается («Отказано в доступе»).**
> Агент перечисляет процессы, читает пути к их файлам и открывает сетевые таблицы. Списки детекции
> (имена майнеров, скриптовые хосты, подозрительные каталоги) вынесены в `rules.txt` именно поэтому:
> когда эти строки были вшиты в бинарник, Kaspersky блокировал собранный exe как дроппер.
> Если блокировка всё же возникла — добавьте папку проекта в исключения
> (Kaspersky: «Настройки → Безопасность → Угрозы и исключения → Управлять исключениями»),
> затем запустите `run.bat`.
> Приложению также нужны права администратора для чтения путей системных процессов.

### Сборка по отдельности

```bat
build.bat                            :: TS + CSS + агент + иконка/версия/манифест
cargo +stable-x86_64-pc-windows-gnu build --release --manifest-path agent\Cargo.toml
scripts\brand.bat                    :: только встраивание иконки и версии в exe
```

Агент собирается GNU-тулчейном (`stable-x86_64-pc-windows-gnu`) с линковщиком `rust-lld` —
это настроено в `.cargo/config.toml` и не требует установленного MSVC.

Иконка собирается из `public/icon.png` утилитой `tools/icobuild` (свой PNG-декодер и запись ICO),
встраивается `rcedit` в `scripts/brand.bat`.

## API агента

Все эндпоинты доступны только на `127.0.0.1`.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/meta` | Версия, хост, модель CPU, доступность GPU |
| GET | `/api/snapshot` | Полный срез телеметрии + оценка здоровья |
| GET | `/api/processes` | Процессы и число аномалий |
| GET | `/api/autoruns` | Автозагрузка |
| GET | `/api/connections` | TCP-соединения |
| POST | `/api/scan` | Полная проверка безопасности |
| GET | `/api/scan` | Последняя выполненная проверка |
| GET | `/api/health` | Оценка и рекомендации |
| GET | `/api/history` | История оценок |
| GET | `/api/fps` | Сессии frametime (включая демо) |
| POST | `/api/fps/import` | Импорт CSV по пути (резервный вариант) |
| GET | `/api/optimize` | Список действий |
| POST | `/api/action` | Выполнить действие по `id` |
| POST | `/api/process/kill` | Завершить процесс |
| GET/POST | `/api/settings` | Настройки |
| POST | `/api/app/quit` | Закрыть окно и агент |

## Ограничения

- **Права администратора.** Без них часть системных процессов недоступна для чтения пути и проверки подписи —
  интерфейс показывает, сколько процессов было пропущено, и не называет проверку полной.
- **Температура и частота GPU** читаются через NVML и доступны только для NVIDIA.
  Для остальных карт плитка честно показывает «датчик недоступен».
- **FPS** не перехватывается «из коробки» (для этого нужен ETW/PresentMon-драйвер):
  модуль анализирует только импортированные захваты.
- **Базы угроз.** Проверка хешей выполняется по локальным правилам; облачные базы не используются,
  чтобы не отправлять данные о системе наружу.
- Диагностика безопасности в стиле «убить всё подозрительное» намеренно не автоматизирована:
  приложение предлагает действие, а решение остаётся за пользователем.

## Только реальные данные

В приложении нет демонстрационных значений: всё, что видно на экранах, измерено на этом компьютере.

- Нет захватов FPS — экран показывает пустое состояние с предложением импортировать CSV.
- Компонент оценки без данных (например, охлаждение без датчика GPU) показывается прочерком
  и не участвует в общем балле; веса пересчитываются по измеренным компонентам.
- Балл защиты до полной проверки считается по реально прочитанному автозапуску, а не по константе.
- Если подпись удалось проверить не у всех процессов, результат называется «Проверено частично»,
  а не «Чисто».
- Настройки «резервная копия автозагрузки» и «проверка при запуске» действительно влияют на поведение агента.

## Безопасность

- Агент слушает только `127.0.0.1` и не имеет аутентификации — это локальный инструмент для одного пользователя.
- Телеметрия, история и резервные копии автозапуска хранятся в `%LOCALAPPDATA%\PCSentinel`.
- Перед отключением автозапуска команда записывается в `autorun-backup.txt`.
- Удаляются только файлы старше 7 дней из папки `%TEMP%`.
